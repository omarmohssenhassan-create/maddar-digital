# Maddar Digital

موقع تعريفي عربي/إنجليزي لشركة حلول رقمية، مع تجارب كاشير ومنيو ومخزون تعمل داخل المتصفح ببيانات تجريبية.

## التشغيل محليًا

افتح `START.cmd` من مجلد `project` أو من مجلد `digital-business`. يبدأ الموقع في الخلفية ويفتح المتصفح على `http://127.0.0.1:4173`. يمكنك إغلاق نافذة التشغيل؛ الموقع يظل يعمل. فتح `START.cmd` مرة أخرى يعيد استخدام الموقع المفتوح بدلًا من تشغيل نسخة ثانية والتسبب في خطأ بالمنفذ.

مع تثبيت Node.js 22 أو أحدث، يمكنك استخدام `npm start` من مجلد المشروع لنفس التشغيل التلقائي. يوجد أيضًا Node محمول داخل `.tools` يستخدمه `START.cmd` دون تثبيت أو تعديل إعدادات الجهاز. الموقع لا يحتاج إلى تنزيل حزم لتشغيله. للتشغيل في الطرفية استخدم `npm run dev`. ولتشغيل الموقع دون فتح المتصفح استخدم `START.cmd --no-open`. عند فشل التشغيل تظهر رسالة واضحة، وتوجد سجلات الخادم داخل `.qa/local-server.out.log` و`.qa/local-server.err.log`.

## الصفحات

- الرئيسية: `#/`
- من نحن: `#/about`
- الخدمات: `#/services/web` و`apps` و`erp` و`pos` و`menu` و`marketing`.
- التجارب: `#/demos`
- الكاشير: `#/demo`
- المنيو التفاعلي: `#/demos/menu`
- المخزون التفاعلي: `#/demos/inventory`
- طلب عرض: `#/contact?service=menu&activity=restaurant`
- الخصوصية: `#/privacy`

استخدم `?lang=ar` أو `?lang=en` قبل علامة `#` لمشاركة رابط بلغة محددة. اختيار اللغة يُحفظ على الجهاز. تغيير اللغة يحافظ على الفاتورة والطلب التجريبي وحركات المخزون وبيانات نموذج التواصل طوال الجلسة.

## أين تعدّل المحتوى؟

- `dist/config.js`: اسم الشركة، اللوجو، صورة الواجهة، رابط الدومين، رقم الواتساب، فيسبوك، الإيميل، رابط دخول العملاء، الخدمات والأنشطة ومزاياها بالعربية.
- `dist/locales-en.js`: تفاصيل الشركة والخدمات والأنشطة بالإنجليزية.
- `dist/messages.js`: النصوص المشتركة باللغتين.
- `dist/experience-content.js`: نصوص الإضافات الجديدة والأسئلة الشائعة وأصناف المنيو والمخزون التجريبية. كل نص جديد يحتوي على العربية ثم الإنجليزية.
- `dist/home.js`: ترتيب أقسام الصفحة الرئيسية وصفحة من نحن.
- `dist/views.js` و`dist/app.js`: صفحات الخدمات والنموذج والكاشير والتنقل.
- `dist/experiences.js`: واجهات المنيو والمخزون والتجارب والأسئلة الشائعة.
- `dist/demo-engine.js`: قواعد كميات المنيو وحركات المخزون. `dist/engine.js`: منطق الكاشير والتحقق من الهاتف.
- `dist/identity.css`: الهوية الأساسية. `dist/experience.css`: تطوير التصميم والعرض المتجاوب.
- `dist/studio.js` و`dist/studio.css`: الافتتاحية السينمائية وكروت الخدمات المصوّرة ومراحل التنفيذ والتحكم في الفيديو.
- `company.film` و`company.filmPoster` داخل `config.js`: الفيديو وصورة المعاينة لكل لغة.

الصور الأصلية محفوظة دون تعديل في `dist/assets/maddar-logo-original.jpeg` و`dist/assets/maddar-brand-banner.jpeg`.

## التواصل والديموهات

رقم الواتساب في الإعدادات بصيغة دولية `201212213033`؛ يظهر كأيقونة وQR فقط. الإيميل `info@MaddarDigital.com` ورابط فيسبوك قابلان للتعديل من الإعدادات. عند ترك رابط الدخول فارغًا يختفي زر دخول العملاء.

نموذج التواصل يتحقق من الحقول ويجهّز رسالة واتساب. العميل يراجع الرسالة ويضغط إرسال داخل واتساب بنفسه. لا توجد قاعدة بيانات لبيانات النموذج، ولا يتم إرسال بريد تلقائي أو تنفيذ مدفوعات. أوصاف المشروع الجاهزة تُضاف للنص المكتوب بدلًا من مسحه.

ديمو الكاشير يمنع بيع كمية غير متاحة ويخصم المخزون بعد البيع التجريبي. ديمو المنيو يعرض ملخصًا فقط ولا يرسل طلبًا للمطعم. ديمو المخزون يمنع الصرف الزائد ويحدّث الأرصدة والتنبيهات وسجل الحركات، ويمكن تصدير بياناته التجريبية إلى CSV. كل تجربة مستقلة، والتغييرات مؤقتة وتُمسح عند إعادة تحميل الصفحة أو الضغط على إعادة التجربة.

## التحقق

- `npm test`: اختبارات منطق الكاشير والمنيو والمخزون والتحقق من الهاتف، وتشغيل الموقع وإعادة فتحه والتعامل مع المنفذ المشغول.
- `npm run test:browser`: التنقل والكاشير والنموذج والعرض المتجاوب.
- `npm run test:i18n`: اللغتان وحالة النماذج والفاتورة وتغييرات اللغة.
- `npm run test:whatsapp`: فحص روابط الواتساب وفك QR من الصورة وعدم ظهور الرقم.
- `npm run test:experience`: المنيو والمخزون والتنبيهات والتصدير والأسئلة الشائعة وطلبات العروض والعرض المتجاوب.
- `npm run test:studio`: فيديوهات MP4 بالعربية والإنجليزية، مدتها وأزرار تشغيلها، تقليل الحركة، وسياسة المحتوى ورقم الواتساب الجديد.

فيلما Maddar أصليان، مدة كل منهما حوالي ١٨ ثانية دون صوت، برسوم للواجهات وحلول الشركة، من غير استخدام فيديو أو محتوى الموقع المرجعي. ملفات MP4 موجودة في `dist/assets/maddar-film-ar.mp4` و`maddar-film-en.mp4`، ولكل لغة صورة معاينة JPEG خفيفة. الفيديو يُحمّل عند ظهوره ويقف عند مغادرة الجزء المرئي. عند تفعيل تقليل الحركة أو توفير البيانات ينتظر التشغيل اليدوي. لإعادة توليد الفيديوهات شغّل المعاينة ثم `npm run media:film`؛ مصدر الرسوم الأصلي هو `scripts/brand-film-canvas.js`.

اختبارات المتصفح تستخدم Playwright الموجود داخل `.tools/qa` وChrome المثبت، ويمكن تحديد مسار متصفح آخر عبر `CHROME_PATH`. عند تنزيل المشروع على جهاز جديد، شغّل `npm install --prefix .tools/qa playwright@1.65.0 jsqr@1.4.0` مرة واحدة لتجهيز أدوات اختبارات المتصفح. هذه الأدوات غير مطلوبة لتشغيل الموقع أو `npm test`.

أدوات الجهاز المحلية `.tools`، تقارير `.qa`، ملفات البيئة، ونسخ النشر المولدة لا تُرفع إلى المستودع.

## تحديث الموقع المنشور

شغّل `npm run package:site` لإنتاج المجلد `release/maddar-digital-upload` وملف ZIP بنفس الاسم. يحتويان على ملفات تشغيل الموقع فقط، مع `index.html` في الجذر. لا ترفع مجلد المشروع أو `.tools` أو `node_modules`.

في Cloudflare افتح `Workers & Pages` ثم `summer-scene-5d09` ثم `New deployment`، وارفع مجلد النشر المحدث وانشره على Production. يظل `maddardigital.com` و`www.maddardigital.com` مربوطين بنفس التطبيق، ولا تحتاج لتغيير DNS عند التحديث.

راجع `release/DEPLOYMENT.md` لبيانات النشر و`release/deployment-manifest.json` لبصمات ملفات الحزمة.

أضيفت بيانات المشاركة وOrganization وrobots وsitemap للواجهة الرئيسية بلغتيها. الصفحات الداخلية ما زالت تستخدم تنقل `#`؛ نقل كل خدمة إلى رابط مستقل وفهرسة مستقلة يحتاج مرحلة إضافية في بنية التوجيه. لا توجد أسعار خدمات أو شهادات عملاء أو أرقام أداء غير حقيقية.
