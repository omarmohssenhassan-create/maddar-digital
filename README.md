# موقع حلول رقمية للأعمال

موقع عربي باتجاه RTL، بدون إطار عمل أو اعتماديات للتشغيل. ملفات النشر الجاهزة داخل dist.

## التشغيل

- افتح dist/index.html مباشرة في المتصفح، أو شغّل خادمًا محليًا:
- بعد تثبيت Node.js إصدار 22 أو أحدث: npm start
- افتح http://127.0.0.1:4173
- على Windows يمكن تشغيل START.cmd، ويستخدم نسخة Node المحلية إن وُجدت.
- npm test لتجارب منطق البيع والتحقق. اختبار المتصفح: npm run test:browser بعد تثبيت Playwright كأداة تطوير فقط: npm install --prefix .tools/qa playwright. يتطلب Chrome، أو ضبط CHROME_PATH لمسار متصفح Chromium.

## تعديل المحتوى

- dist/config.js: اسم الشركة، الوصف، اللوجو، رقم واتساب، رابط دخول العملاء، تفاصيل الخدمات، الأنشطة، وأصناف الديمو.
- company.logo: مسار صورة محلية مثل assets/logo.svg. ضع الصورة داخل dist/assets.
- company.whatsapp: رقم الشركة الحقيقي بالصيغة الدولية، مثل كود الدولة ثم الرقم بدون صفر البداية. اتركه فارغًا لإخفاء روابط واتساب. لا يوجد رقم وهمي مفعّل.
- company.clientLoginUrl: رابط HTTPS لنظام العملاء المستقل. اتركه فارغًا لإخفاء الزر.
- services: عدّل العناوين والجمهور والمزايا بعد التأكد من نطاق الخدمات الفعلي قبل النشر.
- dist/styles.css: الألوان والخطوط والتجاوب.
- dist/views.js: محتوى الصفحة الرئيسية وصفحات الخدمات والتواصل.
- dist/app.js: التنقل والنموذج وتفاعلات الكاشير.
- dist/engine.js: منطق الكميات والفواتير والتحقق.
- prices في demoProducts بالقروش (8500 تعني 85 جنيهًا).

## التواصل والخصوصية

عند ترك رقم الشركة فارغًا، يمكن للزائر تجهيز ملخص الطلب ونسخه فقط، ويظهر بوضوح أنه لم يُرسل. لا يوجد خادم لاستقبال الطلبات، ولا حفظ لبيانات النموذج أو إرسال تلقائي.

بعد ضبط رقم واتساب، ينتقل الزائر من النموذج إلى محادثة برسالة مجهزة. يظل الضغط على إرسال داخل واتساب مسؤولية الزائر. الزر العام لواتساب وزر دخول العملاء يظهران فقط بعد إدخال إعداد صالح.

## الديمو

المنتجات والأسعار والمخزون تجريبية. البيانات في ذاكرة الصفحة، وتتغير الكميات بعد إتمام البيع فقط. العودة بين الصفحات تحافظ على التجربة داخل نفس الصفحة، وإعادة التحميل أو زر إعادة التجربة يعيدان البداية. لا تسجيل أو دفع، ولا بيع حقيقي أو ضرائب محاسبية أو نظام عملاء ضمن هذه النسخة.

## الصفحات والنشر

- الرئيسية: #/
- الكاشير: #/demo
- الخدمات: #/services/pos و #/services/erp و #/services/web و #/services/marketing
- التواصل: #/contact?service=pos
- تنقل hash يعمل على أي استضافة ملفات ثابتة بدون إعداد إعادة كتابة الروابط.
- ارفع محتويات dist إلى استضافتك. الخط محلي، ولا يحتاج الموقع اتصالًا بخدمات خارجية حتى يتم فتح واتساب أو نظام العملاء.
- لا توجد أسعار خدمات أو شهادات أو أرقام أداء مختلقة. النماذج المعروضة تصورات توضيحية.
